## Lessons

Early development surfaced the importance of GitHub Codespaces usage discipline, VS Code migration care, avoiding duplicate project/app folders, environment mismatch risk, regular git commits and pushes, rebase/merge conflict awareness, clean `.gitignore` behavior for pycache/venv artifacts, reproducible startup commands, and launcher/health diagnostics.
