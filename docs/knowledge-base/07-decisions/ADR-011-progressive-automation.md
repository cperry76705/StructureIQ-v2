## Decision

Move from manual signal execution to approval-required assisted execution to optional Autopilot rather than enabling full automation immediately.

## Consequences

Automation expands only as validation, safety, and user authority controls mature.

Subscription progression follows Explorer → Professional → Elite, while AI Authority Level remains user-selectable within the tier's maximum authority.
