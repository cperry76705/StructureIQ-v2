## Decision

All plans receive the same premium visual quality.

This is reinforced by the Intelligence Equality Principle: plans should also receive the same core StructureIQ intelligence experience.

## Consequences

Subscription differences should be expressed primarily through execution authority, operational capability, broker integration, automation, and workflow permissions, not cheaper-looking UI or intentionally degraded intelligence.
