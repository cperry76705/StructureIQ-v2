## Purpose

Provide secure premium access to the authenticated StructureIQ workspace.

## Key Visual Decisions

- Two-column financial SaaS layout.
- Large StructureIQ brand and Welcome Back message.
- Security panel with bank-grade security, mandatory MFA, real-time intelligence, and trusted-trader messaging.
- Trusted/security footer.

## Key Interaction Decisions

- Google sign-in is available.
- Email/password sign-in includes show/hide password.
- Remember this device and forgot password are visible.
- No Apple sign-in.
