## Workflow

1. Major decision occurs.
2. Relevant Knowledge Base entry is updated.
3. ADR is added when architectural/product reasoning changes.
4. Release entry is updated for code changes.
5. Generated Bibles/manuals are updated from the Knowledge Base.
6. Git commit includes documentation changes.
